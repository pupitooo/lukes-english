No "will" after when / if

After when, if, as soon as, once, until, before, after, talk about the future in the present. The will goes in the other half of the sentence.

❌ ✅
When the build will finish, I'll deploy it. When the build finishes, I'll deploy it.
If it will work, I'll call you. If it works, I'll call you.
I'll wait until he will reply. I'll wait until he replies.

Drill

  1. I'll send you the link as soon as the upload ___ (finish).
  2. If the pipeline ___ (pass), we'll release tonight.
  3. I'll call you when I ___ (be) back at my desk.
  4. Once the client ___ (approve) the design, we'll start coding.
  5. If there ___ (be) a problem, the system will send an alert.
  6. Don't push anything until the code freeze ___ (end).
  7. If we ___ (find) the bug today, the demo will be fine.
  8. I'll restart the server after the patch ___ (arrive).
  9. If the new job ___ (work out), I'll need more English.
  10. Before the meeting ___ (start), I'll check the slides.

The Solution Frame

Step What it does Phrases
1. Problem One sentence. What hurt? Let me start with the problem. / The issue was that... / Every week we lost...
2. Context Why it mattered, to whom This mattered because... / It affected... / On top of that...
3. Options What you considered We looked at three options. / First... Second... Third... / We could have...
4. Recommendation What you chose So I'd recommend... / We went with... because... / The main reason is...
5. Trade-off and risks What it costs, honestly The trade-off is that... / The risk is... / To be fair, ...
6. Next step What happens now If you agree, the next step is... / As soon as we get the green light, ...
