💻 Class 3: What If? Conditionals 0 to 3

The four conditionals

type if half other half when work life
0 if + present present always true, how a system behaves If the import fails, the system sends an alert. If you heat water to 100 degrees, it boils.
1 if + present will + verb real, possible future If we deploy today, the clients will have it tomorrow. If it rains, I'll stay at home.
2 if + past would + verb unreal or unlikely, now or future If I had more time, I would learn Rust too. If I won a million, I would still work.
3 if + had + past participle would have + past participle the past that did not happen If we had tested it, we wouldn't have lost the data. If I had known, I would have come.
mixed if + had + past participle would + verb a different past, a different now If I had learned Scala at school, I would be faster now. If I hadn't moved, I wouldn't know her.

No will, no would in the if half

Kdybych nastoupil, čekali by hodně. If I would join If I joined, they would expect a lot.
Kdybych byl tebou... If I was you (spoken) If I were you, I wouldn't sign it.

Czech kdyby is two English tenses

Czech about now or the future about the past
Kdybych to věděl, řekl bych ti to. If I knew, I would tell you. If I had known, I would have told you.

Spoken: I would have = I'd have, sounds like "I'd've". would have = would've. wouldn't have = wouldn't've.

Other ways to say if

word meaning example
unless if not Unless you back it up, you'll lose it.
as long as, provided that only if You can deploy on Friday as long as somebody is on call.
as soon as, when time, still no will As soon as it's ready, I'll tell you.
in case to be prepared Take a backup in case the migration fails.
otherwise if not, after a full sentence Back it up, otherwise you'll lose it.
