3were. If I were you. No would in the if half.

4would have found. Type 3: if + had + past participle, would have + past participle.

5had read. Type 3: no would in the if half. If they had read.

6finishes. No will after as soon as, when, if.

7fixes. unless = if not, so no second not, and no will.

8would write. Type 2, not real now: if + past, would.

9had had. Type 3. had had is correct: had + the past participle of have.

10would be. Mixed: a different past, a different now.

11in case. in case = to be prepared.

12as long as. as long as = only if.

13would. Type 2 question: what would you do if + past.

14had known. Type 3: if I had known, I would have come.

15If I had gone there yesterday, I would have seen it.. Včera, so the past: if I had gone, I would have seen.
