If I go, if I went, if I had gone

English Czech when
if I go, I will see it jestli půjdu, uvidím to real, future
if I went, I would see it kdybych šel, viděl bych to not real, now or future
if I had gone, I would have seen it kdybych šel (včera), viděl bych to past, it did not happen

The two halves

type if half other half
0 if + present present
1 if + present will + verb
2 if + past would + verb
3 if + had + past participle would have + past participle
mixed if + had + past participle would + verb

No will and no would in the if half.

Other ways to say if

word meaning
unless if not
as long as, provided that only if
as soon as, when time, still no will
in case to be prepared
otherwise if not, after a full sentence
