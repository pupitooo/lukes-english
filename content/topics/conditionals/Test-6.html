12 vět · různé situace a časy · bez skórování překladu

U každé věty vyber variantu, přelož ji a pak odhal vzorovou odpověď. Překlad můžeš porovnat s vlastním: význam se může vyjádřit více správnými způsoby. Tlačítkem „Hotovo“ si variantu označ, až ji procvičíš. Typ zůstává skrytý do odhalení odpovědi.

V1 = základní tvar slovesa · V2 = minulý tvar · V3 = příčestí minulé.

Přehled typů podmínek

Zero · obecné pravidlo
If + present simple, present simple.Co se děje vždy, obvykle nebo pokaždé, když nastane podmínka.
First · reálná budoucí možnost
If + present simple, will + V1.Možná budoucí situace a její výsledek. V části s if běžně nedáváme will.
Second · představa teď nebo v budoucnu
If + past simple / were, would + V1.Hypotetická nebo méně pravděpodobná situace; minulý tvar vyjadřuje odstup od reality.
Third · jiná minulost
If + had + V3, would have + V3.Představujeme si minulost, která už se nestala a kterou nelze změnit.
Mixed · minulá příčina, současný výsledek
If + had + V3, would + V1.Minulou událost si představíme jinak a mluvíme o jejím následku teď.

Věty lze stavět také s unless (= if not), as long as / provided that (= jen pokud) nebo časovým when / as soon as. Po těchto časových spojkách se pro budoucnost používá přítomný tvar.
