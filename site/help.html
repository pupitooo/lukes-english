Další malý krok.

Nové materiály přidáš přes GitHub. Po uložení se samy objeví ve studovně, obvykle během několika minut.

1. Připrav složku

Pro každou lekci nebo vlastní téma vytvoř jednu složku:

  • Lekce s Lukem: content/lessons/2026-11-09/
  • Vlastní téma: content/topics/nazev-tematu/

Vlož do ní HTML testy, zápisky, MP3 a přílohy. Soubory, které na sebe odkazují, ponech pohromadě pod původními názvy.

2. Nahraj soubory

  1. Otevři složku content v repozitáři ↗.
  2. Na počítači zvol Add file → Upload files a přetáhni připravenou složku do lessons nebo topics.
  3. Ulož změny tlačítkem Commit changes do větve main.

Pokud složka ještě neexistuje, můžeš nejdřív přes Add file → Create new file vytvořit její meta.json podle vzoru níže a pak do ní nahrát ostatní soubory.

Při nahrávání přes web GitHubu může mít jeden soubor nejvýše 25 MB. Větší nahrávky do 100 MB nahraj přes Git. Veřejné materiály může otevřít kdokoli s odkazem.

3. Otevři studovnu

Po dokončení publikování na GitHubu ↗ obnov knihovnu. Nová lekce nebo téma už bude v přehledu. HTML se otevře jako stránka, MP3 v přehrávači a ostatní přílohy půjdou stáhnout.

Zpět do knihovny →
Volitelně: vlastní název, popis a pořadí lekce

Do nové složky přidej soubor meta.json. Pro lekci může vypadat takto:

{
  "title": "Explaining solutions",
  "description": "Analogie a vysvětlování vlastní práce.",
  "date": "2026-11-09",
  "number": 2,
  "tags": ["Mluvení", "Poslech"],
  "files": {
    "Homework.html": {
      "title": "Domácí test",
      "kind": "test"
    }
  }
}

U vlastního tématu stačí title, description a tags. Bez metadat se použije název složky a titulky HTML souborů. Soubory s „test“ nebo „quiz“ v názvu se automaticky označí jako testy.

Označení „hotovo“ se pamatuje pouze v daném prohlížeči. Mezi počítačem a mobilem se nepřenáší. Samotné testy si zachovávají původní způsob vyhodnocení.
