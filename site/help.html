A LIBRARY THAT GROWS WITH YOU

Another lesson.
Another small step.

Add new materials through GitHub. Once saved, they will appear in your study space automatically, usually within a few minutes.

1. Prepare a folder

Create one folder for each lesson or personal topic:

  • Lessons with Luke: content/lessons/2026-11-09/
  • Personal topics: content/topics/topic-name/

Add your HTML tests, notes, MP3 files and attachments. Keep related files together and preserve their original names so links keep working.

2. Upload your files

  1. Open the content folder in the repository ↗.
  2. On a computer, choose Add file → Upload files and drag your prepared folder into lessons or topics.
  3. Save with Commit changes on the main branch.

If the folder does not exist yet, use Add file → Create new file to create its meta.json using the example below, then upload the other files into it.

GitHub’s web upload limit is 25 MiB per file. Use Git for larger recordings up to 100 MiB. These materials are public and can be opened by anyone with a link.

3. Open your study space

Once publishing on GitHub ↗ finishes, refresh the library. Your new lesson or topic will be listed. HTML opens as a page, MP3 files have a player, and other attachments can be downloaded.

Optional: a custom title, description and lesson number

Add a file named meta.json to your new folder. For a lesson, it could look like this:

{
  "title": "Explaining solutions",
  "description": "Analogies and explaining your work.",
  "date": "2026-11-09",
  "number": 2,
  "tags": ["Speaking", "Listening"],
  "files": {
    "Homework.html": {
      "title": "Homework test",
      "kind": "test"
    }
  }
}

For a personal topic, title, description and tags are enough. Without metadata, the library uses the folder name and HTML page titles. Files with “test” or “quiz” in their names are automatically labeled as tests.

Turn test questions into Anki practice

When reviewing a supported test, use the checkbox next to each graded question. Incorrect answers are selected by default; correct answers can be selected too. Use Vygenerovat prompt pro Codex in the review panel, then copy the prompt or use your phone’s share sheet.

The prompt includes only selected, graded questions, your answers, the correct answers and the available explanations. It asks Codex to follow your existing Anki rules and check for duplicates before creating cards. Generating or sharing a prompt does not add cards on its own.

On a computer with the Codex desktop app, Vložit do Codexu (počítač) opens a new chat with the prompt prefilled. On mobile, copy and paste the prompt into Codex, or share it to an available app. Desktop link documentation ↗

Done markers are saved in the current browser only and do not sync between your computer and phone. Graded answers stay locked; use New attempt to try again. Test explanations and Anki review controls may be in Czech.
